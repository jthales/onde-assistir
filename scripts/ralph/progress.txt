## Codebase Patterns
- Backend lives in /workspace/backend (Node.js + Express + TypeScript)
- Frontend lives in /workspace/frontend (Angular, standalone components)
- Git repo is at /workspace/.git; run git commands from /workspace
- The Gemini model to use is `gemini-2.0-flash-lite` (most generous free quota; gemini-1.5-flash is NOT available on this API key)
- Always strip markdown code blocks from Gemini responses before JSON.parse
- CORS is configured for http://localhost:4200 in the backend
- Angular: use `npm install --no-bin-links` (WSL2 chmod restriction); tsc binary at node_modules/typescript/bin/tsc
- Angular typecheck: `node node_modules/typescript/bin/tsc --noEmit` from /workspace/frontend
- Angular app config is at src/app/app.config.ts; add providers like provideHttpClient() there
- Jogo interface is defined at frontend/src/app/models/jogo.ts (mirrors backend types.ts)
